# Townlight Parks Reconciliation

The canonical catalog defines Townlight Parks as parks and recreation support: program and facility Q&A, registration assistance that links to existing systems, policy lookup, maintenance request triage via Townlight 311, and plain-English program descriptions.

v0.1.0 intentionally ships deterministic foundations only. It does not process payments, enroll participants, manage participant records, reserve facilities, dispatch crews, replace Townlight 311, call live LLMs, or ship parks connector runtime.
